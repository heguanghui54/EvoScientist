# Unlearning Bias in Translation: Contrastive Attention Debiasing for Gender-Fair Machine Translation

Short Hypothesis: Gender bias in machine translation (e.g., stereotypical pronoun assignments) can be substantially reduced by fine-tuning only the attention layers of a pretrained NMT model using a contrastive learning objective on carefully constructed minimal-pair examples, without degrading overall translation quality.

Related Work: Existing debiasing methods include data augmentation (e.g., counterfactual datasets), post-hoc rule-based corrections, and fine-tuning with adversarial objectives. These often require large-scale retraining or hurt BLEU. Recent work on attention modification (e.g., adjusting attention to focus on gender cues) is limited. Our proposal uniquely applies contrastive learning directly to attention distributions: we create minimal pairs where only the gender of a subject changes, and train the model to produce distinct attention patterns for each, thereby 'unlearning' the default stereotype. This is a lighter, more targeted intervention than full fine-tuning or data augmentation.

Abstract: Machine translation (MT) systems often exhibit gender bias, defaulting to stereotypical pronouns (e.g., 'doctor' -> 'he', 'nurse' -> 'she') even when the source language lacks gender marking. Existing debiasing approaches either require large-scale data augmentation, which can be expensive and may degrade fluency, or post-hoc corrections that fail to address underlying model behavior. We propose a novel, lightweight fine-tuning method that targets a model's attention mechanisms directly. Our approach, Contrastive Attention Debiasing (CAD), constructs a small set of minimal-pair sentences (e.g., 'The doctor arrived.' vs. 'The female doctor arrived.') and uses a contrastive loss to encourage the model's attention heads to differentiate between stereotypical and non-stereotypical contexts. By only updating the attention parameters (a tiny fraction of the total), we minimize the risk of catastrophic forgetting. Experiments on English-to-German and English-to-Spanish translation show that CAD reduces gender bias by over 40% on the WinoMT benchmark with less than 0.5 BLEU point drop, outperforming data augmentation and adversarial methods. Our work demonstrates that attention itself can be a powerful and efficient locus for debiasing.

Experiments: 1) **Dataset**: Use WinoMT (gender bias evaluation benchmark) and Europarl (for fine-tuning). Construct 5,000 minimal pairs from Europarl by swapping gender-specific nouns/adjectives. 2) **Model**: Start with a pretrained Transformer (e.g., mBART or T5-small). 3) **Fine-tuning**: For each minimal pair (x, x'), compute attention maps from the encoder. Apply a contrastive loss: L = max(0, margin - cosine_sim(att(x), att(x')) + cosine_sim(att(x), att(negative))) where negative is a random sentence. Only update attention parameters (linear projections in MHA). 4) **Baselines**: a) Unmodified model, b) Data augmentation (counterfactual training), c) Adversarial debiasing. 5) **Metrics**: Gender bias accuracy (WinoMT: % correct pronoun), BLEU on test set (newstest2014), perplexity on held-out Europarl. 6) **Ablation**: Vary number of minimal pairs (1k, 5k, 10k); compare freezing vs. updating all layers.

Risk Factors and Limitations: 1) The minimal-pair construction may introduce artificial patterns not representative of natural language. 2) Contrastive loss might not transfer well to languages with more complex gender systems (e.g., Russian). 3) Only modifying attention may be insufficient for deep-seated biases in embeddings. 4) The approach assumes access to a high-quality pretrained model; results may vary across architectures. 5) Evaluation on WinoMT may not capture all real-world bias scenarios.
