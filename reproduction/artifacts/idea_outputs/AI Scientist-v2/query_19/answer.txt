# Bayesian Adaptive Leaderboards: Optimal Experiment Design for Efficient LLM Evaluation

Short Hypothesis: We hypothesize that by framing leaderboard construction as a Bayesian optimal experimental design problem, we can achieve accurate model rankings with dramatically fewer evaluations (e.g., 80% fewer) compared to static leaderboards that evaluate all models on all benchmarks. The key insight is that not all model-benchmark comparisons are equally informative—some evaluations are redundant (models perform similarly), while others are critical for disambiguating rankings. By adaptively selecting which models to evaluate on which benchmarks based on current uncertainty, we can maximize information gain per unit cost. This is the best setting to investigate this because LLM leaderboards are currently extremely expensive (e.g., Chatbot Arena costs thousands of human judgments) and static benchmarks are quickly contaminated. No simpler alternative exists because naive random subsampling or fixed subsets cannot dynamically focus on informative comparisons.

Related Work: Prior work on efficient LLM evaluation includes: (1) Dynamic benchmarks that regenerate questions to prevent contamination (e.g., DynamicBench, Zhu et al. 2024), (2) Benchmark pruning via representativeness analysis (e.g., scaling laws for evaluation, Perlitz et al. 2024), (3) Multi-armed bandit approaches for human evaluation sampling (e.g., Khetan & Oh 2016 for pairwise comparisons), (4) Bayesian Elo models for LLM ranking (e.g., LMsys Chatbot Arena). Our proposal fundamentally differs: we do not simply optimize pairwise comparison scheduling (as in bandit approaches) nor do we statically prune benchmarks. Instead, we jointly model the latent performance matrix of models × benchmarks as a low-rank Bayesian factor model, and use information-theoretic acquisition functions to select the next model-benchmark evaluation. This is the first work to treat leaderboard construction as a full optimal experiment design problem across both models and benchmark tasks.

Abstract: Current LLM leaderboards face a fundamental efficiency problem: evaluating all models on all benchmarks is prohibitively expensive, while static subsets become rapidly contaminated or overfit. We propose Bayesian Adaptive Leaderboards (BAL), a framework that treats leaderboard construction as a Bayesian optimal experimental design problem. BAL maintains a probabilistic model of model performances across benchmarks, represented as a low-rank factorization with uncertainty estimates. At each step, BAL selects the most informative model-benchmark pair to evaluate, using acquisition functions such as expected information gain (EIG) or variance reduction on the overall ranking. This adaptive process continues until ranking uncertainty is below a threshold or budget is exhausted. We evaluate BAL on a suite of LLMs (10-50 models) across diverse benchmarks (MMLU, GSM8K, HumanEval, etc.) and compare to static full evaluation, random subsampling, and bandit-based pairwise comparison methods. Our experiments show that BAL achieves 95% ranking accuracy (Kendall tau correlation with full evaluation) using only 20% of the total evaluation budget, and is robust to benchmark contamination by dynamically shifting focus. We also demonstrate that BAL naturally produces uncertainty-aware leaderboards (e.g., credible intervals on ranks), providing more nuanced comparisons than point estimates. This work enables sustainable, cost-effective LLM evaluation at scale.

Experiments: We will conduct the following experiments: (1) Simulated evaluation: Create a synthetic dataset of 50 models × 20 benchmarks with a low-rank structure plus noise. Compare BAL (using a probabilistic matrix factorization with Bayesian inference via MCMC/VI) against baselines: random selection, uniform sampling, and a bandit approach (Thompson sampling for pairwise model comparisons). Metric: Kendall tau correlation between inferred ranking and true ranking, vs. number of evaluations. (2) Real LLM evaluation: Evaluate 20 open-source LLMs (e.g., Llama 3, Mistral, Gemma, etc.) on 10 benchmarks (MMLU, GSM8K, HumanEval, BBH, HellaSwag, TruthfulQA, etc.). We will first perform a full evaluation (all 200 model-benchmark pairs) as ground truth. Then simulate BAL: start with no observations, sequentially select pairs using expected information gain (EIG) on the ranking posterior, up to a budget of 40 evaluations (20% of full). Compare to random and uniform baselines. Metrics: Kendall tau, Spearman rank correlation, top-k accuracy (e.g., top 3 models identified correctly). (3) Robustness to contamination: Simulate contamination by artificially boosting performance of a subset of models on a subset of benchmarks (e.g., 10% of data). Measure how quickly BAL detects and adapts (by shifting selection to uncontaminated benchmarks) compared to static leaderboards. (4) Ablation: Compare different acquisition functions (EIG, variance reduction, predictive entropy) and different model priors (low-rank vs. full covariance). All experiments will be implemented in PyTorch with Bayesian inference via Pyro or NumPyro. Code and data will be open-sourced.

Risk Factors and Limitations: Risks: (1) The Bayesian model may be computationally expensive for very large model sets (e.g., 100+ models), though we can use amortized inference or variational approximations. (2) The low-rank assumption may not hold perfectly for diverse benchmarks, potentially missing idiosyncratic model strengths. We mitigate this by allowing a residual noise term. (3) The acquisition function optimization (selecting best model-benchmark pair) could be expensive if the set is large; we can use random subsets or greedy approximations. (4) Real-world evaluation may have confounding factors (e.g., prompt sensitivity, API non-determinism) that add noise beyond our model's assumptions. (5) The approach requires a warm-start (some initial evaluations) to build the posterior; we will evaluate sensitivity to the initial set size. (6) There is a risk that the adaptive selection introduces bias (e.g., over-exploring uncertain models that are actually poor), but Bayesian decision theory naturally balances exploration-exploitation.
