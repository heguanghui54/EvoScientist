# Attention Anchors: A Curriculum Learning Approach for Emergent Long-Context Understanding in LLMs

Short Hypothesis: Standard autoregressive language models fail to generalize to long contexts because they are trained with a uniform next-token prediction loss that does not incentivize the model to attend to distant information. By introducing a curriculum learning objective that progressively increases the distance of 'attention anchors'—specific tokens in the past that are critical for predicting future tokens—we can teach the model to develop an emergent ability to retrieve and utilize information from arbitrarily long contexts, without modifying the architecture or increasing the training context window.

Related Work: Existing work on long-context LLMs focuses on architectural modifications (e.g., sparse attention, position embedding extrapolation like HiRoPE, LongLLaDA) or retrieval augmentation (e.g., Landmark Embedding). These methods either require architectural changes or external memory. In contrast, our proposal is a pure training-time intervention: we modify the loss function during training to emphasize predictions that depend on distant tokens. This is related to curriculum learning (Bengio et al., 2009) and the idea of 'attention sinks' (Xiao et al., 2023), but we are the first to propose a dynamic curriculum that explicitly anchors attention to distant context. Unlike prior work that assumes long-context understanding requires architectural or inference-time changes, we hypothesize that the model can learn this capability if properly incentivized during training.

Abstract: Large language models (LLMs) exhibit a surprising inability to utilize information from long contexts, even when the context window is large enough. This failure is often attributed to attention dilution or the 'lost-in-the-middle' phenomenon. We propose a novel training paradigm, Attention Anchor Curriculum (AAC), that directly addresses this limitation. AAC operates by constructing training examples where a target token can only be correctly predicted by attending to a specific 'anchor' token located at a variable distance in the past. During training, we systematically increase this anchor distance, creating a curriculum that forces the model to learn to attend over longer ranges. Crucially, AAC does not require any architectural changes, additional memory, or a larger context window than the model was originally designed for. It simply modifies the training data distribution and loss weighting to emphasize long-range dependencies. We hypothesize that this curriculum induces an emergent ability for long-context retrieval and understanding. We will evaluate our method on standard long-context benchmarks (e.g., LongBench, Zero-SCROLLS, Needle-in-a-Haystack) using a pre-trained LLM (e.g., LLaMA-2-7B) fine-tuned with AAC. We expect to see significant improvements in tasks requiring long-range reasoning, such as multi-document QA and narrative understanding, without degrading performance on short-context tasks. This work challenges the assumption that long-context capability requires architectural innovation and instead highlights the power of training signal design.

Experiments: We will conduct experiments using the LLaMA-2-7B model (or a smaller proxy like Pythia-1B for faster iteration). The key intervention is the creation of a curriculum training set. We will generate synthetic data: for each sequence, we insert a unique 'anchor' token (e.g., a random string like 'XKCD-42') at a specific position. Later in the sequence, we insert a query that asks for the anchor token's value, and the loss is only computed on the token that must be predicted based on the anchor. The distance between anchor and query is varied from 1 to the model's maximum context length. We create a curriculum by starting with short distances and gradually increasing the maximum distance over training steps. We compare against: (1) Fine-tuning on the same data but with random distances (no curriculum), (2) Vanilla fine-tuning on long-context data (e.g., books), (3) State-of-the-art methods like Position Interpolation (PI) and NTK-aware scaling. Evaluation metrics: (1) Accuracy on the synthetic anchor retrieval task, (2) Performance on LongBench (subset of tasks requiring long-range dependency, e.g., NarrativeQA, QMSum), (3) Perplexity on long sequences (up to 32k tokens), (4) Attention pattern analysis (e.g., entropy, distance of attended positions). We will also test generalization to unseen context lengths (extrapolation).

Risk Factors and Limitations: 1. The synthetic anchor task may be too simplistic and not transfer to real-world long-context understanding. We mitigate this by also evaluating on realistic benchmarks. 2. The curriculum might cause catastrophic forgetting of short-context abilities. We will monitor performance on standard short-context benchmarks (e.g., GLUE, MMLU). 3. The computational cost of generating curriculum data and fine-tuning on long sequences may be high, but we use efficient implementation and smaller proxy models. 4. The method may only work for retrieval-type tasks and not for tasks requiring complex multi-hop reasoning over long contexts. 5. There is a risk that the model learns to use the anchor token as a 'cheat' rather than learning general long-context attention. We will vary anchor types and positions to ensure generalization.
