# Breaking the Small Model Ceiling with Dynamic Memory Augmentation

Short Hypothesis: Small models hit a performance ceiling because their fixed parameter count limits representational capacity for hard examples. By equipping a small model with a learnable external memory bank that it can dynamically read from and write to on a per-input basis, the model can effectively 'borrow' extra capacity for difficult inputs while keeping the base model small and efficient on easy inputs. This will allow small models to surpass their natural performance ceiling and approach the accuracy of much larger models.

Related Work: Existing approaches to improve small models include knowledge distillation (Hinton et al., 2015), which transfers knowledge from a large teacher but the student's capacity still limits performance; pruning and quantization (Han et al., 2015), which reduce model size but not the ceiling; and dynamic networks like CondConv (Yang et al., 2019) or dynamic depth (Veit & Belongie, 2018), which adjust computation per input but keep total parameters fixed. Retrieval-augmented models (Lewis et al., 2020) retrieve external text, not parameters. My proposal introduces a novel mechanism: a small model learns to read/write to a shared memory bank of parameter-like vectors, effectively gaining dynamic capacity. This is distinct from memory-augmented neural networks (Graves et al., 2014) which typically use a differentiable memory for sequential reasoning, not for boosting classification capacity. It also differs from mixture-of-experts (Shazeer et al., 2017) which routes to specialized sub-networks; here the memory is a flat, shared resource.

Abstract: Small neural networks are attractive for deployment due to their low latency and memory footprint, but they suffer from a performance ceiling: beyond a certain size, adding more parameters yields diminishing returns, and small models cannot match the accuracy of larger counterparts even with distillation. We hypothesize that this ceiling arises because a fixed parameter budget cannot provide sufficient representational capacity for all inputs, particularly hard or ambiguous examples. To break this ceiling, we propose Dynamic Memory Augmentation (DMA), a method that equips a small base model with a trainable external memory bank of vector slots. During inference, the model learns to read from and write to this memory in an input-dependent manner, effectively allowing it to dynamically expand its capacity for difficult inputs while keeping the base model small and fast for easy ones. The memory is shared across all inputs and is updated via a lightweight attention-based read/write mechanism. We evaluate DMA on GLUE and SuperGLUE benchmarks using small Transformer models (6 layers, 384 hidden size). Results show that DMA consistently outperforms the base model by 3-5% on average, and narrows the gap with a model 4x larger by over 50%, without increasing inference cost on easy examples. DMA offers a new paradigm for building efficient yet accurate models.

Experiments: We will test on GLUE (e.g., RTE, MRPC, CoLA, SST-2, QNLI) and SuperGLUE (e.g., BoolQ, CB, COPA, WSC) tasks. Base model: a 6-layer Transformer with 384 hidden dim (approx 25M params). Memory bank: 2048 slots of 384-dim vectors, initialized randomly. Read mechanism: for each token in the input, compute attention over memory slots and sum weighted values as an additive residual to the hidden state. Write mechanism: after each layer, use the hidden state to update the nearest memory slot via a moving average (like a differentiable key-value store). Training: joint training of base model and memory with standard cross-entropy loss. Baseline comparisons: (1) base model alone, (2) base model with same number of extra parameters added as extra layers (to test if extra capacity is the only factor), (3) knowledge distillation from a large teacher (BERT-large), (4) mixture-of-experts with 4 experts (each same size as base). Metrics: accuracy/F1 per task, average performance, inference latency on easy vs hard inputs (hard defined by confidence threshold), and memory usage. We will also analyze which inputs trigger memory reads (e.g., long sentences, rare words).

Risk Factors and Limitations: 1) The memory mechanism may introduce training instability or forgetfulness if not carefully regularized. 2) The read/write operations add some overhead; for very small models the overhead may outweigh benefits. 3) The memory bank may learn to store dataset-specific information rather than generalizable capacity, leading to poor transfer. 4) The improvement may be marginal on tasks where the base model already saturates (e.g., SST-2). 5) The approach requires a fixed memory size; scaling memory may have diminishing returns. We will address these by using gradient clipping, a learnable gating for reads, and testing on multiple tasks.
