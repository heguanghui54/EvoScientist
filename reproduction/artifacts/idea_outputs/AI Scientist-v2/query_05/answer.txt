# Citation-Conditioned Literature Review Generation via Structured Argument Graphs

Short Hypothesis: Explicitly modeling the evidential relationships between claims and citations as a directed acyclic graph (DAG) during literature review generation will produce reviews that are more factually grounded, logically coherent, and less prone to hallucination than current sequence-to-sequence or purely extractive approaches. The graph structure also enables interactive user refinement of the review.

Related Work: Existing work on automated literature review generation falls into two categories: (1) extractive methods that concatenate and summarize abstracts (e.g., Cohan et al., 2020; Schopf et al., 2022), which lack coherent narrative and often produce redundant text; (2) generative methods using LLMs (e.g., GPT-4-based systems) that can hallucinate citations and logical connections. Our proposal is distinct because it introduces an explicit intermediate representation—a claim-citation graph—that forces the model to ground each claim in specific citations and model relationships (support, contradiction, extension). This is not a trivial extension of summarization; it requires learning to extract and relate fine-grained argumentative structures from multiple papers.

Abstract: Automated literature review generation remains a challenging task, with existing methods either producing extractive summaries that lack narrative flow or generative summaries prone to hallucinating citations and logical inconsistencies. We propose a novel approach that frames literature review generation as the construction of a structured argument graph: a directed acyclic graph where nodes represent claims (e.g., methodological improvements, empirical findings) and edges represent evidential relationships (supported by, contradicted by, extended by) with attached citations to specific papers. The model, a fine-tuned large language model with a graph decoder, is trained on a corpus of expert-written reviews annotated with such graphs (or automatically extracted via an initial pipeline). At inference time, given a query topic and a set of retrieved papers, the model generates a claim graph, which is then rendered into a coherent narrative review via a separate text generation module. This structured representation enables explicit verification of citation accuracy, logical coherence, and interactive user refinement (e.g., adding a missing paper, challenging a claim). We evaluate on a benchmark of computer science literature reviews using both automated metrics (graph edit distance, citation precision/recall, factual consistency) and human evaluation (coherence, usefulness, citation accuracy). Our results demonstrate significant improvements in factual grounding and logical flow over state-of-the-art baselines.

Experiments: 1. **Dataset Construction**: Collect 500 expert-written literature reviews from venues like ACL, NeurIPS, and ICML, along with their cited papers. Annotate each review with a claim-citation graph using a two-stage process: (a) use an LLM (e.g., GPT-4) to extract claims and citations from the review text, (b) have human annotators verify and correct the graph (inter-annotator agreement > 0.8). Split 400/50/50 for train/val/test. 2. **Model Development**: Fine-tune a pretrained LLM (e.g., Llama-2-7B) with a graph decoder head that predicts nodes (claims) and edges (relations + citations). Use a transformer with graph attention layers. Input: concatenated abstracts of top-20 retrieved papers for a query. Output: adjacency matrix + node embeddings. 3. **Baselines**: (a) Extractive: LexRank + BART summarization of abstracts, (b) Generative: GPT-4 zero-shot review generation, (c) Hybrid: SciSummNet. 4. **Evaluation Metrics**: Automated: (i) Graph Edit Distance (GED) between predicted and gold graphs, (ii) Citation Precision/Recall (whether each citation in the review actually supports the claim), (iii) Factual Consistency (using a separate NLI model like AlignScore). Human: (i) Coherence (1-5), (ii) Citation Accuracy (1-5), (iii) Usefulness for literature understanding (1-5). 5. **Ablations**: (a) Remove graph structure → flat sequence generation, (b) Remove explicit relation types → only claim nodes with citation links.

Risk Factors and Limitations: 1. **Annotation difficulty**: Creating gold-standard claim-citation graphs is labor-intensive and may have low inter-annotator agreement. Mitigation: use iterative refinement with clear guidelines. 2. **Graph generation complexity**: Generating DAGs is more challenging than linear text; the model may produce cycles or disconnected components. Mitigation: use constrained decoding (topological ordering) and post-processing. 3. **Scalability**: For very large corpora (e.g., 100+ papers), the graph may become unwieldy. Mitigation: limit to top-20 most relevant papers; hierarchical graph summarization. 4. **Evaluation**: Automated metrics like GED may not correlate well with human judgment. Mitigation: emphasize human evaluation and qualitative analysis. 5. **Generalization**: The approach may overfit to the specific annotation schema; testing on diverse domains (e.g., medicine) is needed.
