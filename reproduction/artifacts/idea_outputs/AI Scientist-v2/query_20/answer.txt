# PID: Per-Input Diversity – A New Lens for Evaluating Text Generation Diversity

Short Hypothesis: Current corpus-level diversity metrics (e.g., distinct-n, self-BLEU) conflate per-input diversity (variety for the same prompt) with cross-input diversity (variety across different prompts), leading to misleading evaluations. We hypothesize that per-input diversity is a more meaningful and actionable measure for creative text generation tasks, and that it can be measured simply by aggregating diversity metrics within multiple samples per input. This setting is ideal because it isolates the model's stochastic capability, which is critical for applications like story generation, where users want multiple distinct continuations for a single prompt. There is no simpler way to answer this question than to directly compute within-input diversity and compare to standard corpus metrics.

Related Work: Existing work on diversity in NLG includes corpus-level metrics like distinct-n (Li et al., 2016), self-BLEU (Zhu et al., 2018), and embedding-based metrics (e.g., average cosine distance). Sampling methods like top-k, nucleus sampling (Holtzman et al., 2020), and temperature scaling have been studied for their effect on diversity, but evaluation is typically done via corpus-level metrics. The MAUVE metric (Pillutla et al., 2021) compares distributions but still operates at the corpus level. Perplexity and BLEU measure quality, not diversity. Our proposal is novel because it explicitly separates per-input from cross-input diversity, providing a fine-grained evaluation that reveals model behaviors (e.g., memorization vs. true stochasticity) that corpus metrics obscure. No existing work, to our knowledge, systematically studies this distinction and proposes a dedicated evaluation framework.

Abstract: Diversity is a crucial aspect of text generation quality, especially for creative applications like story generation, dialogue, and data augmentation. Current evaluation practices rely on corpus-level metrics such as distinct-n, self-BLEU, or embedding distances computed over a set of generated texts from different prompts. However, these metrics conflate two distinct phenomena: the model's ability to produce varied outputs across different inputs (cross-input diversity) and its ability to produce varied outputs for the same input (per-input diversity). In this work, we argue that per-input diversity is often the more relevant quantity for practical use cases, as it measures the model's capacity to generate multiple distinct plausible continuations for a single prompt. We propose a simple yet effective evaluation framework, Per-Input Diversity (PID), which computes diversity metrics (e.g., distinct-n, embedding distance, or entropy) within a set of N samples generated per input, and then averages these scores across all test inputs. Through controlled experiments on language models with varying sampling strategies (temperature, top-k, nucleus) and model sizes, we demonstrate that PID reveals significant differences in model behavior that are invisible to corpus-level metrics. For instance, a model with high corpus diversity may actually have near-zero per-input diversity if it simply memorizes diverse training examples. We also introduce PID-Entropy, a metric based on the estimated entropy of the per-input generation distribution, and show its robustness. Our work provides a new, more precise tool for evaluating and improving diversity in text generation.

Experiments: We will conduct experiments on two text generation tasks: story generation (using the WritingPrompts dataset) and open-ended dialogue (using the Persona-Chat dataset). For each task, we will fine-tune a GPT-2 medium model as a base. We will create controlled variants by varying: (1) sampling temperature (0.7, 1.0, 1.5), (2) top-k sampling (k=10, 50, 100), (3) nucleus sampling (p=0.8, 0.9, 0.95), and (4) repetition penalty (1.0, 1.2, 1.5). For each variant, we will generate N=20 samples per test input (100 test inputs). We will compute: (a) Corpus-level metrics: distinct-1, distinct-2, self-BLEU, average pairwise cosine distance (using Sentence-BERT). (b) Per-input diversity metrics: per-input distinct-1, per-input distinct-2, per-input average pairwise cosine distance, and PID-Entropy (estimated using k-NN density estimation in the Sentence-BERT embedding space, with k=5). Additionally, we will conduct a human evaluation where annotators rate the diversity of 5 randomly selected samples per input on a Likert scale, for a subset of 20 inputs across 5 model variants. We will compare how well corpus metrics vs. PID metrics correlate with human judgments, using Spearman rank correlation. We will also include a baseline where we artificially create a 'memorizing' model by training on a small dataset and generating exact training samples, to show that corpus metrics fail to detect lack of per-input diversity.

Risk Factors and Limitations: 1. The choice of N (number of samples per input) may affect PID scores; we need to study sensitivity. 2. PID requires multiple generations per input, increasing computational cost. 3. The entropy estimation via k-NN may be noisy for small N. 4. Human evaluation is subjective and expensive; we mitigate by using a small subset. 5. Our controlled experiments may not fully capture real-world model differences (e.g., different architectures). 6. The proposal focuses on diversity, not quality; we do not address how to combine both. 7. The distinction between per-input and cross-input diversity may not matter for tasks where only one output per input is needed (e.g., machine translation).
