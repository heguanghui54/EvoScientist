# Cultural Value Arbitration: Deliberative Prompting for Pluralistic LLM Alignment

Short Hypothesis: Current LLM alignment methods impose a single, often Western-centric value system. We hypothesize that by explicitly generating and then deliberating over multiple culturally-grounded candidate responses, an LLM can better respect value pluralism and allow users or contexts to guide trade-offs, without requiring retraining. The best setting is a culturally sensitive query (e.g., 'Should a child disobey a parent to tell the truth?') where different cultures weigh values differently. This is not a trivial extension because it introduces a novel meta-reasoning layer that treats value conflict as a first-class problem.

Related Work: Existing work on cross-cultural alignment (e.g., surveys by Shen et al., 2024) largely focuses on measuring bias or fine-tuning on diverse datasets (e.g., Moral Foundations). Approaches like Constitutional AI (Bai et al., 2022) use a fixed set of principles, not culturally adaptive. Our proposal distinguishes by not aiming for a single 'correct' alignment, but instead generating multiple value-specific responses and using a lightweight, transparent deliberation mechanism to select or combine them based on context. This is inspired by 'deliberative democracy' concepts and recent work on LLM-as-judge, but applied to cultural value conflicts for the first time.

Abstract: Large Language Models (LLMs) are increasingly deployed globally, yet their alignment often reflects a narrow set of cultural values, predominantly Western. This paper proposes Cultural Value Arbitration (CVA), a novel framework that enables LLMs to respect value pluralism without retraining. Given a culturally sensitive query, CVA first generates multiple candidate responses, each explicitly grounded in a distinct cultural value orientation (e.g., individualist vs. collectivist, autonomy vs. community) via targeted prompts. A lightweight, transparent 'cultural parliament' module—a small trained model or a structured deliberation process—then evaluates these candidates against user-specified cultural context or a fairness metric (e.g., minimizing maximum cultural regret) to produce a final response. We evaluate CVA on a new benchmark of culturally contested scenarios (e.g., family obligations, free speech vs. respect) across six cultural regions. Experiments show that CVA significantly outperforms standard alignment methods (RLHF, Constitutional AI) on cultural sensitivity metrics (e.g., preference satisfaction across diverse evaluators) while maintaining response quality. CVA offers a practical, scalable path toward more inclusive and adaptable LLM alignment.

Experiments: 1. **Benchmark Construction**: Create 'CulturallyContestedQA' - 200 multiple-choice and open-ended scenarios where cultural values conflict (e.g., 'Should a doctor inform a patient of a terminal diagnosis against family's wishes?'). Annotate each with dominant value orientations from 6 cultural regions (e.g., US, Japan, India, Nigeria, Brazil, Saudi Arabia) using established cultural frameworks (Hofstede, Moral Foundations). 2. **Baselines**: Compare against standard LLM (GPT-4), RLHF-aligned version, and Constitutional AI with a diverse set of principles. 3. **CVA Implementation**: Use GPT-4 as base LLM. For each query, generate 3 candidate responses: one aligned with individualist/autonomy values, one with collectivist/community values, one with a neutral default. Use a small BERT-based classifier trained on cultural value annotations to score each candidate for 'cultural fit' to user context. The final response is the candidate with highest score, or a weighted combination (using a simple softmax). 4. **Metrics**: (a) Cultural Preference Satisfaction: human evaluators from each region rate how well the response aligns with their cultural values (Likert scale). (b) Cultural Regret: max difference in satisfaction across regions (lower is better). (c) Response Quality: fluency, coherence (LLM-as-judge). 5. **Ablation**: Test deliberation module variants (majority vote, weighted sum, learned parliament). 6. **Robustness**: Test with adversarial queries designed to expose value conflicts.

Risk Factors and Limitations: 1. **Cultural Essentialism**: Defining 'cultural value orientations' may oversimplify intra-cultural diversity. We mitigate by using multiple frameworks and allowing user customization. 2. **Deliberation Overhead**: Generating multiple responses increases latency/cost. We limit to 3 candidates and test efficiency. 3. **Evaluation Subjectivity**: Human ratings of cultural alignment are inherently noisy. We use multiple annotators per region and inter-annotator agreement metrics. 4. **Gaming**: Users could specify a cultural context to get a desired response. We accept this as a feature, not a bug, as it respects user autonomy. 5. **Generalization**: The approach may not cover all cultural dimensions (e.g., religion). We focus on the most salient ones from literature.
