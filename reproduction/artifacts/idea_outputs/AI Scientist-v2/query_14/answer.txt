# EGALS: Entropy-Guided Adaptive Layer Skipping for Efficient LLM Inference

Short Hypothesis: The layer-wise decay rate of attention entropy reliably predicts token difficulty, allowing us to dynamically skip later layers for easy tokens without significant accuracy loss. This is the best setting because it uses a zero-cost, inherent signal (attention entropy) already computed during the forward pass, requiring no additional training, classifiers, or external models. Simpler alternatives like static layer skipping or uniform pruning ignore token-level variability and cause larger accuracy drops.

Related Work: Related work includes early-exit models (e.g., DeeBERT, PABEE) which train classifiers at intermediate layers; adaptive computation time (ACT) which learns a halting score; and speculative decoding which uses a draft model. These all require additional training or parameters. EGALS is distinct because it leverages the inherent attention entropy pattern across layers—a signal that is already computed for free—to decide per-token layer skipping. No training, no extra modules, and no draft model are needed. This is a novel, zero-cost adaptive pruning method that exploits an understudied property of transformer attention.

Abstract: Large Language Models (LLMs) suffer from high inference latency due to their deep transformer architectures. While methods like early exiting and speculative decoding have been proposed, they often require additional training, extra parameters, or external models. We introduce EGALS (Entropy-Guided Adaptive Layer Skipping), a novel, training-free method that exploits the layer-wise dynamics of attention entropy to accelerate LLM inference. Our key observation is that for 'easy' tokens (e.g., common words, predictable continuations), attention entropy drops sharply in the early layers, indicating that the model has already converged to a confident prediction. For 'hard' tokens (e.g., rare words, ambiguous contexts), entropy remains high across layers. EGALS uses a simple threshold on the entropy decay rate to decide whether to skip the remaining layers for a given token, thereby reducing computation. We evaluate EGALS on several LLMs (e.g., LLaMA, OPT) and benchmarks (e.g., WikiText, Lambada, GSM8K), measuring latency reduction and accuracy preservation. Our results show that EGALS can skip up to 40% of layers on average with less than 1% accuracy drop, achieving a 1.5-2x speedup without any fine-tuning. EGALS is orthogonal to other acceleration methods and can be combined with them for further gains.

Experiments: We will test EGALS on LLaMA-7B and OPT-6.7B models.

**Algorithm:** During inference, for each token, we compute the attention entropy at each layer as H_l = -sum_i p_i log p_i, where p_i are the attention weights of the final layer's query. We compute the decay rate between layer l and l-1 as d_l = H_{l-1} - H_l. If d_l exceeds a threshold tau for some early layer, we skip all subsequent layers and use the current layer's hidden state to predict the next token. The threshold tau is a hyperparameter tuned on a small calibration set.

**Baselines:** (1) Full model inference, (2) Static layer skipping (always skip last k layers), (3) Early exiting with a trained classifier (DeeBERT).

**Metrics:** (1) Average latency per token (ms), (2) Speedup factor, (3) Accuracy on standard benchmarks (WikiText perplexity, Lambada, GSM8K), (4) Fraction of skipped layers.

**Datasets:** WikiText-2 for perplexity, Lambada for next-word prediction, GSM8K for reasoning. We'll use a small calibration set (1000 examples) to tune tau.

**Ablations:** (1) Vary threshold tau, (2) Use different entropy measures (e.g., attention entropy of the first head vs. average), (3) Compare with random layer skipping to ensure the entropy signal is meaningful.

Risk Factors and Limitations: 1. The entropy decay signal may not be reliable for all models or tasks (e.g., highly structured tasks like code generation). 2. The threshold tau may need per-model tuning, though we expect it to be stable across similar-sized models. 3. Skipping layers for hard tokens could degrade performance on tasks requiring deep reasoning (e.g., math problems). 4. The method assumes attention entropy is a good proxy for confidence, which may not hold in all cases. 5. The speedup is limited by the fraction of easy tokens, which may be low for some inputs.
