# Adaptive Knowledge Refresh via Differentiable Memory Replay for Domain-Specific LLMs

Short Hypothesis: A lightweight, differentiable memory module that can be incrementally updated via replay-based gradient updates can keep domain-specific LLMs current with evolving knowledge (e.g., medical guidelines) without retraining, while preserving general language capabilities. This is the best setting because it directly addresses the practical need for continuous knowledge updates in deployed LLMs, and no existing work combines differentiable memory with replay for this purpose.

Related Work: Existing approaches for domain-specific LLMs include: (1) Static knowledge injection via continued pre-training (e.g., Qilin-Med), which requires full retraining for new knowledge. (2) Retrieval-Augmented Generation (RAG), which retrieves from a static corpus and cannot adapt to knowledge changes without re-indexing. (3) Knowledge editing methods (e.g., MEMIT, ROME) that modify model weights for specific facts but risk catastrophic side effects and are not designed for continuous updates. (4) Adapter-based fine-tuning (e.g., LoRA) which still requires retraining for each knowledge update. Our proposal differs by introducing a separate, differentiable memory module that is updated via a replay mechanism, allowing the base LLM to remain frozen. This is not a trivial extension: it requires designing a memory read/write mechanism that is stable under continual updates and that integrates with the LLM's attention.

Abstract: Domain-specific large language models (LLMs) face a critical challenge: the knowledge they are trained on becomes outdated as guidelines, regulations, and facts evolve. Current solutions require full retraining, expensive fine-tuning, or static retrieval corpora, making continuous knowledge updates impractical. We propose Adaptive Knowledge Refresh via Differentiable Memory Replay (AKR-DMR), a method that equips a frozen domain-specific LLM with a small, differentiable memory module that can be incrementally updated. The memory acts as an external knowledge store that the LLM attends to via cross-attention. When new domain knowledge arrives, we compute gradients to write this knowledge into the memory while replaying a small buffer of previously stored knowledge to prevent catastrophic forgetting. The base LLM's weights remain untouched, preserving its general language capabilities. We evaluate AKR-DMR on a medical QA task where guidelines change annually (e.g., COVID-19 treatment protocols). Experiments show that AKR-DMR achieves accuracy comparable to full retraining on updated knowledge while retaining 95% of performance on older knowledge and maintaining perplexity on general text. This work demonstrates a practical, low-cost pathway to keeping domain-specific LLMs perpetually current.

Experiments: We will use a frozen LLaMA-2-7B model and add a memory module consisting of 64 learned key-value slots (dimension 4096) with a cross-attention layer between the memory and the LLM's final hidden states. The memory is initialized randomly. For each knowledge update (e.g., a set of 100 new medical facts), we: (1) Compute a gradient of the cross-entropy loss (predicting the correct fact) w.r.t. the memory slots, and update the memory via Adam. (2) Simultaneously replay 50 randomly sampled facts from a buffer of previous knowledge (size 500) to prevent forgetting. The buffer is FIFO. We compare against: (a) Full fine-tuning LLaMA on new+old data (upper bound), (b) LoRA fine-tuning on new data only, (c) RAG with a static corpus, (d) Knowledge editing (MEMIT). Evaluation metrics: (1) Accuracy on a held-out set of 200 updated-knowledge questions (e.g., 'What is the new recommended dose for drug X?'), (2) Accuracy on 200 old-knowledge questions (to measure retention), (3) Perplexity on WikiText-2 (to measure general language degradation), (4) Memory update time (seconds per update). We simulate 10 sequential knowledge updates over a year of medical guideline changes.

Risk Factors and Limitations: Potential risks: (1) The memory module may interfere with the base LLM's reasoning, causing hallucinations on unrelated topics. We mitigate this by using a gating mechanism that learns when to attend to memory vs. rely on the base model. (2) The replay buffer may not prevent forgetting if the knowledge distribution shifts drastically. We will experiment with larger buffers and prioritized replay. (3) The memory capacity is limited; very large knowledge bases may require hierarchical memory. (4) The method assumes knowledge can be expressed as factual triples or short documents; complex reasoning knowledge may not fit. (5) The approach requires access to the LLM's hidden states, which may not be available for API-only models. We assume an open-source LLM.
