# AADSQ: Activation-Aware Dynamic Sparse Quantization for Efficient LLM Inference on Edge Devices

Short Hypothesis: We hypothesize that dynamically adjusting the quantization precision of LLM weights and activations at runtime, based on the sparsity and outlier magnitude of the current input's activations, can significantly reduce inference latency and energy on edge devices while maintaining task accuracy, outperforming static quantization schemes that ignore input-dependent variations.

Related Work: Existing work on LLM quantization includes post-training quantization (PTQ) methods like GPTQ (Frantar et al., 2023), AWQ (Lin et al., 2024), and SmoothQuant (Xiao et al., 2023). These methods apply a fixed quantization scheme (e.g., 4-bit weights, 8-bit activations) after calibration on a static dataset. Adaptive quantization methods like Q-BERT (Shen et al., 2020) and HAWQ (Dong et al., 2019) adjust precision per layer but are static after calibration and require extensive retraining. Dynamic mixed-precision methods exist for CNNs (e.g., DNAS) but not for LLMs, and they often rely on reinforcement learning or NAS, which is computationally prohibitive. Our proposal is distinct: we introduce a lightweight runtime predictor that, for each input sequence, observes early activation statistics and dynamically selects per-layer bit-widths (e.g., 4-bit vs. 8-bit) with negligible overhead (<1% extra compute). This is the first work to explore input-adaptive quantization for LLM edge deployment.

Abstract: Deploying Large Language Models (LLMs) on edge devices is challenging due to their massive memory and compute requirements. Quantization is a key compression technique, but existing static methods fail to adapt to the diverse and dynamic nature of real-world inputs, leading to suboptimal speed-accuracy trade-offs. We propose Activation-Aware Dynamic Sparse Quantization (AADSQ), a novel framework that enables runtime, input-adaptive quantization for LLMs. AADSQ uses a lightweight predictor (a 2-layer MLP with <10K parameters) trained to map early-layer activation statistics—specifically, the sparsity ratio and the magnitude of top-k outliers—to an optimal per-layer quantization bit-width (e.g., 4-bit, 6-bit, or 8-bit) for the remaining layers. The predictor is trained offline on a diverse calibration set to minimize a latency-accuracy Pareto objective. At inference, the predictor runs once after processing the first few tokens, then the selected precision is applied to subsequent layers via fast integer kernels. We evaluate AADSQ on OPT, LLaMA, and Phi-2 models deployed on a Raspberry Pi 5 and a Jetson Orin Nano. Experiments show that AADSQ achieves 1.5-2x speedup over static 8-bit quantization with <1% accuracy drop on common benchmarks (MMLU, GSM8K), and outperforms static 4-bit quantization by 5-10% accuracy while maintaining similar latency. This work demonstrates that input-aware dynamic quantization is a practical and powerful approach for LLM edge inference.

Experiments: We will conduct the following experiments: (1) **Predictor Training**: Collect activation statistics (sparsity, outlier magnitude) from a diverse calibration set (5000 samples from C4, WikiText, and instruction-following datasets). Train a 2-layer MLP (input dim=2, hidden=64, output=3 classes: 4-bit, 6-bit, 8-bit) using a loss function that combines accuracy penalty (from a small proxy model) and estimated latency. (2) **Main Evaluation**: Compare AADSQ against baselines: static 4-bit, 6-bit, 8-bit quantization (using GPTQ), and SmoothQuant on OPT-1.3B, LLaMA-7B, and Phi-2 (2.7B). Metrics: accuracy on MMLU (5-shot) and GSM8K (8-shot), average latency per token (ms), energy per token (Joules, measured via power monitor), and model size (MB). Deploy on Raspberry Pi 5 (4GB RAM) and Jetson Orin Nano (8GB RAM). (3) **Ablation Studies**: Test different predictor architectures (decision tree, linear probe), different activation statistics (e.g., mean, variance, entropy), and the impact of early token count (1, 2, 4 tokens). (4) **Robustness**: Evaluate on out-of-distribution inputs (adversarial prompts, different languages) to see if predictor generalizes. (5) **Overhead Measurement**: Measure the time and energy cost of the predictor itself to ensure it is <1% of total inference cost. All code will be open-sourced.

Risk Factors and Limitations: Potential risks: (1) The predictor may not generalize well to very different input distributions (e.g., code vs. natural language), requiring per-domain predictors. (2) The overhead of the predictor, though small, may still be non-negligible on extremely resource-constrained devices (e.g., microcontrollers). (3) The dynamic switching of quantization precision may cause pipeline stalls or memory fragmentation on some hardware, reducing expected speedup. (4) The approach assumes early-layer activations are predictive of later-layer behavior; this may break for very deep models or certain architectures (e.g., mixture of experts). (5) Accuracy drop may be larger for complex reasoning tasks (e.g., math) that require high precision. We will carefully document these failure cases.
