Second, it surveys existing approaches—sparse attention, Rotary Position Embedding (RoPE), retrieval-augmented generation (RAG), and sliding window methods—and synthesizes their strengths and weaknesses. The proposed HiRASP method integrates three tiers: (1) a Hierarchical Sparse Attention (HiSA) engine that uses local windows, strided patterns, and global tokens for multi-resolution attention; (2) an Adaptive Positional Scaling (APS) module that dynamically adjusts RoPE frequencies to enable stable extrapolation to extremely long sequences (e.g., 128K tokens); and (3) a Dynamic Internal Retrieval (DIR) module that maintains an internal memory bank of past hidden states for content-aware retrieval within the same document. Expected contributions are a new hybrid architecture, an adaptive scaling mechanism, a dynamic internal retrieval method, empirical results showing state-of-the-art performance, and open-source implementations.
