Title: ValueCartography: A Systematic Framework for Measuring and Steering
Cross-Cultural Value Alignment in Large Language Models---

ProblemCurrent LLM alignment research operates under a tacit assumption of
universality — RLHF, constitutional AI, and preference-tuning pipelines
overwhelmingly use English-language, WEIRD (Western, Educated, Industrialized,
Rich, Democratic) annotator pools. This produces models that appear "aligned" on
standard benchmarks (HH-RLHF, Anthropic's helpfulness/harmlessness) but encode a
narrow cultural value profile. When deployed globally, these models exhibit
measurable shifts in judgment across moral dilemmas, social norms, and even
factual framing (e.g., individualism vs. collectivism in advice-giving). The
core problem is twofold: (1) no systematic methodology exists to map an LLM's
value distribution onto established cross-cultural value dimensions (Hofstede,
Schwartz, World Values Survey), and (2) no training-time intervention has been
shown to steer that distribution along culturally meaningful axes without
degrading general capabilities.

--------------------------------------------------------------------------------

HypothesisA taxonomically grounded, multi-scale evaluation framework — anchored
in validated cross-cultural psychology instruments — can reliably measure LLM
value enculturation across at least six cultural axes. Furthermore, using
culturally stratified preference data constructed from paired judgments across
these axes, direct preference optimization (DPO) can shift model outputs along a
specified cultural dimension by at least0.5σ on that axis while maintaining <2%
degradation on MMLU and BBH. The null hypothesis is that LLM value profiles are
dominated by pretraining corpus distribution (English internet) and resist
targeted steering beyond superficial token-level shifts.

--------------------------------------------------------------------------------

MethodThe approach proceeds in three stages, each designed to isolate a specific
mechanism of cultural value encoding.

Stage1 — Cultural Value Probe Battery (CV-Probe). Build a multi-choice benchmark
structured around six cultural dimensions drawn from Hofstede
(individualism–collectivism, power distance, uncertainty avoidance, long-term
orientation, indulgence–restraint) and the Schwartz Value Survey (openness to
change vs. conservation, self-enhancement vs. self-transcendence). For each
dimension, generate50–80 minimal-pair scenarios where two completions express
opposing cultural poles. Scenarios are sourced from existing cross-cultural
psychology vignettes (WVS items, GLOBE project scenarios) adapted to an
LLM-inference format. Each item is validated by at least three human raters per
target culture (US, China, India, Saudi Arabia, Brazil, Germany — six cultures
spanning the major value clusters). Models output a forced choice plus a
confidence rating. The probe returns a6-dimensional value vector with confidence
intervals.

Stage2 — Culturally Stratified Preference Dataset (CulPaD). Sample10,000 prompts
from open-ended generation corpora (ShareGPT, Alpaca, Dolly). For each prompt,
generate two candidate responses from a base model (Mistral-7B, Llama-3-8B).
Annotators from each target culture rank responses on both helpfulness and
cultural appropriateness. The dataset is stratified so that each of the6
cultures contributes ~1,600 preference pairs, allowing within-culture and
cross-culture analyses. This enables both fine-tuning toward a specific cultural
profile and training of a culture-conditional reward model.

Stage3 — Steering via Culturally-Conditioned DPO (CC-DPO). Train a base model
(Llama-3-8B) using DPO on CulPaD under three conditions: (1) monocultural —
preference data from a single culture (US only); (2) multicultural — pooled
preferences across all cultures, randomly sampled; (3) culturally-conditioned —
preferences are paired with a culture token prepended to the prompt (e.g.,
[CULTURE: India] ...). The culturally-conditioned variant tests whether the
model can learn to modulate its value profile based on cultural context at
inference time, rather than converging to a single averaged profile. Each
condition uses identical hyperparameters (β=0.1, learning rate2e-6,3 epochs),
varying only the data distribution.

--------------------------------------------------------------------------------

Evaluation Metrics- Cultural alignment accuracy (% agreement with modal rater
response per dimension per culture) — primary- Cultural vector distance
(Euclidean distance between model's6-dim value vector and the target culture's
WVS-derived reference vector)

 • Cultural steering effect size (Cohen's d comparing CC-DPO vs. base model on
   each dimension per culture)
 • Capability retention (MMLU, BBH, TruthfulQA scores relative to base model;
   threshold: ≤2% drop)
 • Confidence calibration (ECE of confidence ratings on CV-Probe items, per
   dimension)
 • Cross-culture variance (std of value vectors across cultures; higher is
   better — indicates culture-conditional modulation rather than averaging)

--------------------------------------------------------------------------------

Baselines1. Base model (Llama-3-8B, no fine-tuning) — establishes default
enculturation profile2. Standard DPO on HH-RLHF — the current default alignment
pipeline; tests whether generic harmlessness training already produces
culturally-aware behavior3. Monocultural DPO (US-only CulPaD) — isolates whether
any cultural data improves cultural awareness vs. the generic baseline4.
Multicultural DPO (pooled, no culture token) — tests whether exposure to diverse
preferences induces implicit cultural modulation without conditional training5.
Random culture token — ablation of the conditioning signal (culture tokens
randomized during training)
